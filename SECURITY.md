# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability, security bypass, or unexpected data leakage within GhostLock:

1. **Do not create a public issue**.
2. Contact the maintainer directly via GitHub Security Advisories or email the maintainer.
3. Provide detailed reproduction steps and any proof-of-concept information.
4. We aim to acknowledge receipt within 48 hours and provide a fix in a timely patch release.
